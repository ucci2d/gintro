# Roadmap Rakan v1 (task in ordine, uno alla volta)

## Fase 1 — MVP
- RAK-T1 Scheletro PWA: index.html, manifest, sw.js, icone, layout responsive (tab bar mobile / sidebar desktop), tema dark, routing con hash (#schede, #clienti, #libreria, #impostazioni, #scheda-<id>).
- RAK-T2 Store: modello dati del brief §4, persistenza locale, dati demo (1 "Cliente demo" + 1 scheda d'esempio), backup export/import JSON.
- RAK-T3 Libreria: carica data/exercises.json, ricerca istantanea, filtri categoria, aggiunta/modifica esercizio e video.
- RAK-T4 Editor scheda: intestazione, giorni, blocchi (serie/circuito/lista), righe esercizio, riordino, superserie.
- RAK-T5 Bottom sheet esercizio: ricerca + prescrizione a chip + lastRx + "Aggiungi e continua".
- RAK-T6 Documento cliente + stampa PDF + testo WhatsApp (brief §7).

## Fase 2 — Rifinitura
- RAK-T7 Nuova scheda: clienti, "duplica ultima scheda", 4 modelli.
- RAK-T8 Impostazioni: nome trainer, logo, colore accento documento, colonna carichi on/off.
- RAK-T9 Passata estetica e mobile (Safari iOS, Android Chrome, desktop affiancato), micro-interazioni.
- RAK-T10 QA completo: checklist del brief §9, correzione bug.

## Fase 3 — Pubblicazione
- RAK-T11 GitHub Pages + istruzioni di installazione su iPhone/Android/PC (docs/INSTALLAZIONE.md).
